# Capítulo 6: Matemáticas Intermedias

> *Basado en el libro de Donald D. Spencer, Editorial Limusa, 1985*

## Introducción

Los problemas presentados en este capítulo pueden usarse en clases de Matemáticas avanzadas de escuelas de educación media y en los cursos del tronco común de Ingeniería. El lector encontrará una amplia selección de problemas de las disciplinas de álgebra, teoría de números, cálculo, análisis numérico, teoría de ecuaciones, matrices, trigonometría y programación lineal.

**110.** Con frecuencia resulta útil encontrar la ecuación de una curva que se ajuste óptimamente a un conjunto dado de puntos.

a) *Caso lineal.* Las ecuaciones para ajustar una línea recta $y = ax + b$ a un conjunto de $N$ puntos $(X_i,\,Y_i)$ son:

$$a\sum X^2 + b\sum X = \sum XY$$

$$a\sum X + bN = \sum Y$$

b) *Caso cuadrático.* Las ecuaciones para ajustar una curva $y = ax^2 + bx + c$ a un conjunto de $N$ puntos $(X_i,\,Y_i)$ son:

$$a\sum X^4 + b\sum X^3 + c\sum X^2 = \sum X^2 Y$$

$$a\sum X^3 + b\sum X^2 + c\sum X = \sum XY$$

$$a\sum X^2 + b\sum X + cN = \sum Y$$

## Problemas adicionales

> *Problemas de elaboración propia, inspirados en el capítulo.*

**114.** Implementar el método de bisección para encontrar una raíz de una función continua $f(x)$ en un intervalo $[a,\,b]$ donde $f(a)$ y $f(b)$ tienen signos opuestos. Iterar hasta que el intervalo sea menor que $10^{-6}$. Probar con $f(x) = x^3 - 2x - 5$ en $[2,\,3]$.

**115.** Resolver un sistema de 3 ecuaciones con 3 incógnitas usando eliminación gaussiana con pivoteo parcial. Probar con el sistema del problema 108.

**116.** Implementar la interpolación de Lagrange para un conjunto de $N$ puntos $(x_i,\,y_i)$. El programa debe evaluar el polinomio interpolador en un punto $x^*$ dado. Probar con los puntos $(0,1)$, $(1,3)$, $(2,2)$, $(3,5)$ y evaluar en $x^* = 1.5$.

**117.** Aproximar la integral de una función mediante la regla de Simpson 3/8:

$$\int_a^b f(x)\,dx \approx \frac{3h}{8}\left[f(x_0) + 3f(x_1) + 3f(x_2) + 2f(x_3) + \cdots + f(x_n)\right]$$

donde $h = (b-a)/n$ y $n$ es múltiplo de 3. Comparar con los resultados del problema 102.

**118.** Calcular el determinante de una matriz $3\times3$ usando la regla de Sarrus, y el de una $n\times n$ usando expansión por cofactores. Verificar con la matriz del problema 81.

**119.** Resolver la ecuación diferencial ordinaria $\dfrac{dy}{dx} = f(x,y)$ usando el método de Euler con paso $h$:

$$y_{n+1} = y_n + h\,f(x_n,\,y_n)$$

Probar con $\dfrac{dy}{dx} = -y$, condición inicial $y(0) = 1$, $h = 0.1$, en $[0,\,2]$. Comparar con la solución exacta $y = e^{-x}$.

**120.** Convertir un número entre las bases 2, 8, 10 y 16 (hexadecimal). El programa debe aceptar un número en cualquiera de las cuatro bases e imprimirlo en las cuatro. Probar con los valores 255, 1023 y 4096 en base 10.
